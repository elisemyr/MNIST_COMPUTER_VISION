# MNIST Training Challenge
Welcome to this introductory Kaggle challenge for the Introduction to Computer Vision course !

This exercise is designed as a practice competition to help you get familiar with the Kaggle interface, the submission process, and the structure of real data science challenges.
There is no prize, no ranking, and no winner. The goal is simply to learn by doing.

### Objective
Your task is to train a model that correctly classifies handwritten digits from the MNIST dataset (0–9). The dataset is one of the most famous benchmarks in machine learning and is perfect for testing basic image classification models.
